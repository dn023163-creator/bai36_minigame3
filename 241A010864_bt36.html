5 Câu Lý Thuyết Cơ Bản Về JavaScript

Tổng hợp câu trả lời ngắn gọn về nền tảng JavaScript.

1) Javascript là gì?

JavaScript (JS) là ngôn ngữ lập trình kịch bản (scripting language) phổ biến dùng để tạo tính tương tác, xử lý logic và cập nhật nội dung động cho trang web (cũng chạy được phía server như Node.js).

2) Mối quan hệ giữa ngôn ngữ Java và Javascript?

Hai ngôn ngữ hoàn toàn khác nhau về cú pháp, kiểu dữ liệu và cơ chế thực thi (Java thiên về OOP, biên dịch chạy trên JVM; JS thông dịch/JIT, chạy trên trình duyệt/JS engine). Tên "JavaScript" xuất phát từ yếu tố lịch sử/thương mại thời kỳ đầu của web chứ không phải biến thể của Java.

3) Các kiểu dữ liệu cơ bản của Javascript?

Gồm kiểu nguyên thủy (Primitive): number, string, boolean, undefined, null, symbol, bigint; và kiểu tham chiếu (Object): object, array, function.

4) Javascript và HTML?

HTML xây dựng cấu trúc và nội dung trang web, còn JavaScript thao tác trực tiếp lên cây DOM và sự kiện của HTML để thay đổi nội dung, giao diện và phản hồi tương tác người dùng theo thời gian thực.

5) Các cách sử dụng Javascript?

Có 3 cách chính: Inline (viết trực tiếp trong thuộc tính sự kiện như onclick="..."), Internal (đặt trong thẻ <script>...</script> trong file HTML), và External (tách ra file .js riêng và nhúng qua <script src="..."></script>).
